# coffee_shop_transactions
Analysis of Coffee Shop Transactions

## Overview
Taking sales from 3 coffee shops and analyzing sales, income, and rush-times to assist in staffing decisions, drinks to prepare, and stock to keep on hand.
The jupyter notebook investigates only drink sales from store 8 for a more thorough investigation. 

## Business Questions
- When are the busiest sales periods and how can staffing be optimized?
- Which drinks drive the most revenue and sales volume?
- Which products require more preparation time and may impact service capacity?
- How do sales trends change over time?

## Tools
SQL, Excel, Python, Power BI, Pandas, Seaborn

## Files
- Coffee_Shop_sales.csv : Original, uncleaned dataset from Kaggle
- coffee_SQL_EDA.sql : my SQL script to explore data utilizing CTEs, window functions, and re-usable views for monthly revenue changes
- store_8_coffee_data.csv : Exported data from store 8 for further exploration
- coffee_notebook_store8.ipynb : jupyter notebook for more in-depth exploration, visualizations, and data transformation for analysis
- coffee_sales_dash.pbix : Power BI dashboard
- coffee_sales_dashboard.pdf : viewable PDF of Power BI Dashboard

## Key Analysis
- Analyzed sales trends across three coffee shop locations
- Identified peak sales periods to understand rush-time patterns
- Compared product popularity and revenue contribution
- Evaluated drink preparation requirements to understand operational impact
